DQ Website UI/UX Concept Breakdown

Reference: Donate Quran / “dq” charity website homepage
Format: Long-scroll donation, distribution, storytelling, and content hub landing page

1. Project Manager Perspective
Page Purpose

This homepage is designed as a faith-based donation and awareness platform for Qur’an distribution. The primary objective is to move users from emotional understanding into clear action:

Understand the mission.
See what is inside the Qur’an package/project.
Trust the organization through real-world distribution proof.
Choose a donation/product route.
Watch educational/social content.
Read blog/knowledge content.
Navigate to related Islamic learning resources.

The page is not only a donation page. It works as a complete campaign landing page for:

Qur’an donation
Qur’an distribution
bulk sponsorship
app awareness
marketing/content awareness
blog and Islamic learning ecosystem
2. Content Hierarchy & User Journey
Main Flow
Order	Section	Purpose
1	Header Navigation	Gives quick access to core pages and donation CTA

22. Accessibility Requirements

The current visual reference is strong, but implementation must improve accessibility.

Required
All images need descriptive alt text.
Yellow buttons must have enough contrast.
CTA text should be at least 13–14px.
Keyboard focus states must be visible.
Carousel should support keyboard navigation.
Blog cards should use semantic <article>.
Header navigation should use <nav>.
Buttons linking to pages should be <a> elements, not button tags.
Suggested Focus Style
:focus-visible {
  outline: 3px solid #f4b000;
  outline-offset: 3px;
}
23. Exact Reproduction Notes

To reproduce the reference accurately, preserve these details:

Yellow and black brand contrast
The yellow is the emotional/action color. Do not overuse it.
Hero text must remain oversized and stacked
The layout depends on the three-line headline.
Use real human distribution photos
The “Greatest Venture” section must not use stock-only imagery.
The product photography must feel premium
Marble, soft light, black Qur’an cover, gold accents.
Story posters should remain vertical
They should feel like social campaign cards, not normal website cards.
The footer must be dark and calm
It anchors the page and reinforces trust.
